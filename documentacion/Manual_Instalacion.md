# 🤖 RoboClean Tycoon - Equipo Zeta

¡Bienvenido a **RoboClean Tycoon**! Este es un proyecto desarrollado para la asignatura de Desarrollo de Aplicaciones Web (DAW1) 2025/2026. 

## 📖 Descripción del Proyecto
RoboClean Tycoon es un juego incremental de gestión donde controlas a un robot de limpieza inteligente. Tu objetivo es limpiar zonas, ganar experiencia, gestionar tus baterías y optimizar las tareas para convertirte en el mejor gestor de limpieza robótica.

---

## 🛠️ Manual de Instalación

El proyecto es una aplicación web estática (HTML, CSS y JavaScript Vanilla), por lo que **no requiere** de la instalación de un servidor complejo ni de bases de datos.

### Requisitos Previos
- Un navegador web moderno (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).
- (Opcional pero recomendado) [Git](https://git-scm.com/) para clonar el repositorio.
- (Opcional) Un editor de código como [Visual Studio Code](https://code.visualstudio.com/) si deseas explorar o modificar el código, junto con la extensión **Live Server**.

### Pasos de Instalación

#### Opción 1: Ejecución Directa (La forma más sencilla)
1. **Descarga el código**: Puedes descargar el proyecto como un archivo `.zip` haciendo clic en el botón verde **"Code"** en la parte superior derecha de GitHub y seleccionando **"Download ZIP"**.
2. **Descomprime el archivo**: Extrae el contenido del archivo `.zip` en una carpeta de tu ordenador.
3. **Ejecuta el juego**: Navega hasta la carpeta `fuentes` y haz doble clic en el archivo `index.html`. El juego se abrirá automáticamente en tu navegador predeterminado.

#### Opción 2: Clonar el Repositorio (Para desarrolladores)
1. Abre tu terminal o línea de comandos.
2. Ejecuta el siguiente comando para clonar el repositorio en tu equipo local:
   ```bash
   git clone https://github.com/jrmartinezs01/Equipo-Zeta-.git
   ```
3. Accede al directorio del proyecto:
   ```bash
   cd Equipo-Zeta-
   ```
4. Navega a la carpeta `fuentes` y abre el archivo `index.html` en tu navegador. Alternativamente, si usas Visual Studio Code, puedes abrir la carpeta del proyecto y usar la extensión **Live Server** para lanzar el juego con recarga automática.

## 🚀 Tecnologías Utilizadas
- **HTML5**: Estructura semántica del juego.
- **CSS3**: Estilos, animaciones, diseño responsivo y barras de progreso.
- **JavaScript (Vanilla)**: Lógica principal del juego, sistema de niveles, experiencia, pathfinding e interactividad.
